# CleanPaste

A tiny macOS menu bar app that strips formatting from text.

Click the menu bar icon, paste anything (web pages, Word, Google Docs, emails…), and copy it back as clean text.

## Install

**Download:** grab `CleanPaste-<version>.zip` from the [latest release](../../releases/latest),
unzip it and drag `CleanPaste.app` to `/Applications`. It is a universal build (Apple Silicon and Intel), macOS 14+.

The app is ad-hoc signed, not notarized. If macOS refuses to open it the first time, right-click the app and choose
**Open**, or run:

```bash
xattr -dr com.apple.quarantine /Applications/CleanPaste.app
```

**Or build it yourself** (needs the Xcode Command Line Tools, `xcode-select --install`):

```bash
./build.sh                 # -> build/CleanPaste.app and build/CleanPaste-<version>.zip
open build/CleanPaste.app
```

## Features

- **Plain text** – removes fonts, colors, sizes, links and styles; keeps paragraphs, lists and tables (tab-separated).
- **Markdown mode** – turn the toggle on to convert the pasted formatting to Markdown instead:
  headings, **bold**, *italic*, ~~strikethrough~~, `inline code`, code blocks, links, nested lists and tables.
- Live preview of exactly what will be copied.
- `⌘↩` copies the result and (optionally) hands focus back to the previous app so you can paste right away.
- **Global shortcut** (default `⌃⌥V`) opens/closes the window from any app. Change it in the `…` menu →
  *Shortcut: … · Change…* and press the new combination.
- Optional **Launch at login** (in the `…` menu).
- Right-click the menu bar icon to quit.

## How it works

Pasted content lands in a rich-text view (`NSTextView`), so formatting is preserved long enough to be analysed.
`Converter.swift` walks the attributed string paragraph by paragraph and emits either plain text or Markdown.
Only a plain `String` is ever written to the pasteboard, which is what removes the formatting.

## Releasing

Bump `CFBundleShortVersionString` in `Info.plist` and push to `main`. The
[Release workflow](.github/workflows/release.yml) builds the universal app and publishes a GitHub Release
(tag `vX.Y.Z` plus the zip) automatically. If that version already has a release, nothing happens.

The app icon is generated by `swift Tools/make-icon.swift` (writes `Resources/AppIcon.icns`).
